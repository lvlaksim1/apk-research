# apk-research v0.11 — Network Analyzer

## Purpose

The Network Analyzer is a post-capture desktop view over the normalized network evidence stored in every Research ZIP.

The raw source of truth remains:

```
01_raw/network/traffic.pcap
```

The analyzer reads:

```
02_normalized/network-flows.json
```

and does not change capture, Android runtime or attribution behavior.

## Flow schema 0.2

A flow is identified by:

```
protocol + endpoint A + endpoint B
```

where endpoint order is canonical and therefore independent of packet direction.

This fixes the v0.10.x fragmentation where one connection could be represented as:

```
UNKNOWN outbound
UNKNOWN inbound
package-owned flow
```

The same packets now produce one flow whose owner evidence can improve over time.

Each flow contains:

- `flow_id`;
- protocol and canonical endpoints;
- oriented local/remote endpoint when known;
- first/last target UTC and duration;
- packet count and captured bytes;
- outbound/inbound/other packet counts;
- outbound/inbound/other captured bytes;
- best owner evidence;
- per-packet confidence counts;
- attributed and unknown packet counts;
- DNS queries;
- TLS SNI.

## GUI

Open a Research ZIP in Results and press **Network Analyzer**.

The Network tab provides:

- owner filter: all / researched application / unknown;
- protocol filter: TCP / UDP;
- free-text search across normalized flow evidence;
- sortable-style tabular connection view;
- full JSON details for the selected flow.

Displayed columns:

```
Time | Owner | Host | Protocol | Local | Remote | ↑ | ↓ | Confidence
```

Host prefers TLS SNI, then DNS evidence, then remote IP.

## Evidence semantics

A connection-level owner is the strongest ownership evidence observed for any packet in that flow. This does not erase uncertainty: `packet_confidence_counts`, `attributed_packet_count` and `unknown_packet_count` show how attribution evolved across packets.

Network ownership is not causal attribution. Timeline action correlation remains temporal-only unless a future evidence source can prove a stronger relation.
