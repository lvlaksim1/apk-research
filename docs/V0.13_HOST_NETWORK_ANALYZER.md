# apk-research v0.13 — Host-oriented Network Analyzer

## Goal

Turn normalized network evidence into a host-first investigation workflow while preserving the existing forensic source hierarchy.

## Evidence hierarchy

```
traffic.pcap
    ↓
network-flows.json (schema 0.2)
    ↓ presentation only
Host group
    ↓
Flow
    ↔
Research Timeline action
```

Host groups are derived UI objects. They are never written back into the Research ZIP and never replace canonical `flow_id` records.

## Host identity

The presentation layer chooses the first available identity in this order:

1. TLS SNI
2. DNS query
3. remote IP
4. `unknown-host`

This is a display grouping rule, not a claim that every IP belongs exclusively to that hostname.

## Host summary

A host aggregates only the flows currently visible after filters. It may show:

- number of flows and packets;
- protocols;
- outbound/inbound captured bytes;
- known package owners plus Unknown state;
- strongest confidence and complete confidence counts;
- remote IPs;
- first/last target timestamps;
- correlated Timeline action IDs.

## Flow details

The underlying flow object remains unchanged. The desktop renderer presents selected fields in a readable form and retains evidence qualifiers such as confidence, ambiguity and temporal-only Timeline correlation.

## Cross-navigation

`correlated_action_ids` provides Network → Timeline lookup. Timeline network references continue to use canonical normalized `flow_id` for Timeline → Network lookup.

No new causal relationship is inferred by the GUI.

## Non-goals

v0.13 does not:

- decrypt TLS;
- modify PCAP;
- change socket attribution;
- change Android collectors;
- change Research ZIP schemas;
- change clean launch;
- change Emulator display/input transport.
