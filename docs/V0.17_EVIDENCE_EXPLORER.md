# v0.17 — Unified Evidence Explorer

## Purpose

Unified Evidence Explorer provides one GUI path through evidence already captured by apk-research. It is a presentation/index layer, not a new evidence source.

## Evidence paths

Forward view:

`Action → Host → Flow → Process/Socket → Raw evidence`

Reverse view:

`Host → Flow → Action / Process/Socket / Raw evidence`

## Source artifacts

The Explorer consumes existing normalized evidence:

- `02_normalized/research-timeline.json`;
- `02_normalized/network-flows.json`;
- `02_normalized/socket-attribution.json`.

It points back to raw sources:

- `01_raw/network/traffic.pcap`;
- `01_raw/network/socket-snapshots.txt`.

## Provenance rules

A flow raw locator includes canonical flow ID, target-time interval, transport and bidirectional endpoint tuple. A socket locator includes process/PID/UID/inode/confidence evidence and the time interval of the associated flow.

The locator is not a copied or transformed replacement for raw evidence. The raw artifact remains authoritative.

Action ↔ Flow correlation remains `temporal-only` and `causal_claim=false`. The Explorer must never present temporal adjacency as demonstrated causality.

## Navigation

The GUI supports direct transitions in both directions among Timeline, Network Analyzer and Evidence Explorer. Free-text search spans actions, hosts, flow IDs, process/PID/socket evidence, endpoints and protocols.

## Compatibility boundary

No Research ZIP schema change is introduced by v0.17.0. Android runtime, collectors, v0.10.5 clean-launch sequencing and hidden Emulator → gRPC/MMAP architecture are unchanged.
