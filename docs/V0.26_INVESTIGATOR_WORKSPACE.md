# v0.26 — Investigator Workspace

## Цель

v0.26 превращает уже существующие Unified Session Evidence, Evidence Explorer и Packet Inspector в единое рабочее место исследователя. Версия не меняет захват, RAW-артефакты, атрибуцию процессов/сокетов, Android runtime или правила причинности.

## Модель данных

Investigator Workspace строится только поверх уже проверенного `build_unified_session_model()` и существующих normalized evidence. Для каждой строки создаётся производная навигационная запись со следующими полями:

- время target/host UTC;
- тип и имя наблюдаемого события;
- `action_id` и связанные `flow_id`;
- наблюдаемые протоколы, удалённые endpoints и process/socket attribution;
- исходный relation type/strength;
- `causal_claim` без повышения силы связи;
- признак доступности экранной навигации.

RAW PCAP остаётся авторитетным источником сетевых доказательств.

## EV-ссылки

Каждая строка получает устойчивую ссылку вида `EV-<digest>`. Digest вычисляется только из идентичности уже существующей строки: времени, kind/name, action ID, flow IDs и sequence.

EV-ссылка является навигационным ключом. Она:

- не создаёт новый факт;
- не усиливает исходную атрибуцию;
- не превращает временную связь в причинную;
- предназначена для закладок, наборов доказательств, отчётов и возврата к исходному представлению.

Для одного неизменного Research ZIP и одной и той же модели ссылка воспроизводима.

## Поиск и фильтры

Workspace поддерживает пересечение фильтров по:

- свободному тексту / EV-ссылке;
- времени UTC;
- виду события;
- протоколу;
- процессу/PID/inode;
- удалённому endpoint/IP;
- `action_id`;
- классу связи.

Фильтрация только исключает строки из представления. Отсутствие результата не является доказательством отсутствия события в реальности.

## Классы связи

Workspace различает как минимум:

- `observed-fact` — непосредственно наблюдаемое/нормализованное событие;
- `technical-relationship` — существующая техническая связь процесса/сокета/потока;
- `temporal-relationship` — временная связь действия и сетевого события;
- `relationship` — иная существующая производная связь без причинного повышения.

Исходные `relation_type`, `relation_strength` и `causal_claim` сохраняются.

## Закладки и наборы доказательств

Пользовательские закладки и именованные наборы сохраняются рядом с архивом в отдельном файле:

`<research.zip>.investigator.json`

Research ZIP не открывается на запись и не изменяется. Состояние содержит только EV-ссылки и пользовательскую организацию материала. При загрузке ссылки, которых больше нет в текущей модели, отбрасываются.

## Навигация

Из выбранной строки Workspace можно вернуться в:

- Session Evidence;
- Timeline;
- Evidence Explorer;
- Packet Inspector;
- контекст экрана.

Переход использует существующие `action_id`, `flow_id` и target UTC. Навигация не повышает доказательную силу исходной связи.

## Отчёт

Отчёт строится только из активного пользовательского набора доказательств и может быть сохранён в Markdown или JSON.

Для каждой записи сохраняются:

- EV-ссылка;
- время;
- класс доказательства/связи;
- action/flow IDs;
- протоколы/endpoints/processes;
- relation type/strength;
- `causal_claim`;
- source-navigation идентификаторы для возврата к исходным данным.

Сам факт включения записи в отчёт является выбором исследователя, а не новым доказательством.

## Границы доказательств

- `01_raw/network/traffic.pcap` остаётся авторитетным сетевым источником.
- Action ↔ Flow и Packet ↔ Action остаются `temporal-only`, `causal_claim=false`.
- Screen links остаются `time-aligned-navigation`.
- v0.25 protocol analysis остаётся `captured-packets-only`.
- Отсутствующие пакеты, события, plaintext и причинность не синтезируются.
- EV-ссылки, закладки, наборы и отчёты являются организационным/навигационным слоем.

## Совместимость

Не меняются:

- hidden Emulator → gRPC/MMAP → AndroidView;
- v0.10.5 startup/clean-launch sequencing;
- dual-source screen role: Continuous Screen для непрерывной временной картины, Android screenrecord для высокого разрешения;
- RAW collectors и Research ZIP evidence schemas.

Audio Evidence и user-facing Virtual Display остаются вне текущего объёма.
