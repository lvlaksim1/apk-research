# v0.23.1 — Sidecar Evidence Isolation & Idle Stability

## Purpose

Correct two defects observed in the first owner-side v0.23 Research ZIP without changing the canonical research runtime or raw evidence.

## Sidecar infrastructure classification

Continuous Screen provenance already records exact dynamic Sidecar control and media ports. During final Timeline/network normalization apk-research reads those ports and marks only packets satisfying all of these conditions:

1. protocol is TCP;
2. both endpoints are loopback;
3. at least one endpoint port matches an archived Sidecar control/media port.

Marked packets are classified as `apk-research-sidecar` infrastructure.

They remain in `01_raw/network/traffic.pcap`. They are excluded only from ordinary target-app flow inventory, Timeline network markers and action correlations. Derived summaries retain explicit infrastructure packet/byte accounting.

## Continuous Screen idle handling

The Sidecar uses short timeouts for connection establishment and control handshakes. The accepted binary media connection is different: after its header is validated it becomes a long-lived blocking stream.

A static screen may legitimately produce no encoded output for an arbitrary interval. Silence is therefore not a timeout condition. Stop/liveness remains coordinated by the separate control channel.

## Regression gates

- unit: inherited media timeout is cleared;
- unit: exact archived Sidecar ports classify only matching loopback packets;
- unit: marked infrastructure remains in source accounting but never becomes an app normalized flow;
- real AVD: 10-second idle screen interval, longer than the former timeout;
- real AVD: Continuous Screen must still complete with clean EOS/cleanup;
- real AVD: exact Sidecar loopback flows must not occur in normalized app inventory.

## Unchanged evidence boundaries

- raw PCAP remains authoritative and unmodified;
- canonical screenrecord remains authoritative;
- Continuous Screen remains experimental/non-canonical;
- Packet ↔ Action remains temporal-only, causal_claim=false;
- hidden Emulator → gRPC/MMAP → AndroidView is unchanged;
- v0.10.5 startup/clean-launch sequencing is unchanged;
- Audio Evidence and Virtual Display remain excluded.
