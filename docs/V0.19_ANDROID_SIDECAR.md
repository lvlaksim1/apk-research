# v0.19 — Android Sidecar Foundation

## Purpose

The sidecar provides a project-owned, temporary Android execution surface for future functions that benefit from a persistent device-side process. v0.19 proves only the infrastructure. It does not collect evidence.

## Non-goals

- no replacement for Emulator gRPC/MMAP display or input;
- no screen-recording migration yet;
- no audio evidence;
- no virtual display;
- no installed Android APK/service;
- no persistent guest configuration.

## Build

`android_sidecar/src/.../Agent.java` is compiled during release builds and converted by Android D8 into a DEX/JAR. The resulting `apk-research-agent.jar` is bundled into the PyInstaller distribution.

The user's computer does not need Java or Android build-tools to run apk-research.

## Runtime lifecycle

1. Host resolves the bundled agent.
2. ADB target readiness is checked.
3. Temporary sidecar directory is created under `/data/local/tmp/apk-research/sidecar`.
4. Agent JAR is pushed.
5. Host binds localhost on an ephemeral TCP port and begins listening.
6. `adb reverse` maps the same device TCP port to that host listener.
7. Host starts `app_process` with the JAR in `CLASSPATH`.
8. Agent connects to `127.0.0.1:<device-port>`, which ADB reverses to the already-listening host.
9. Exact protocol/agent version handshake completes.
10. Commands use the persistent socket.
11. STOP/BYE closes the agent; host removes the reverse mapping and guest JAR.

## Protocol v1

Agent version: `0.1.0`.

Messages are bounded UTF-8 lines:
- `APK_RESEARCH_AGENT 1 0.1.0`
- `HELLO 1 0.1.0`
- `READY 1 0.1.0`
- `PING <token>`
- `PONG <token> <monotonic-ms>`
- `STOP`
- `BYE`

The minimal protocol intentionally avoids a general remote-command surface.

## Acceptance

The real AVD gate proves:
- build output is a usable DEX/JAR;
- push and app_process execution;
- reverse connection without listener polling;
- exact handshake;
- PING/PONG;
- graceful process exit;
- reverse removal;
- guest JAR removal;
- existing gRPC/MMAP transport still works immediately afterward.
