# v0.27 — APK/XAPK Package Intake

## Цель

v0.27 добавляет XAPK как штатный входной формат приложения, не меняя проверенный исследовательский runtime, захват доказательств и формат Research ZIP.

Пользователь выбирает APK или XAPK одним и тем же способом. Дальнейший способ установки определяется программой автоматически.

## Одиночный APK

Путь одиночного APK сохраняется без изменения семантики:

- package name определяется через `aapt2 dump badging`;
- установка выполняется через `adb install -r -t -g`;
- после успешной установки приложение готово к прежнему исследовательскому циклу.

## XAPK

XAPK рассматривается как ZIP-контейнер. Программа не доверяет внешнему `manifest.json` как источнику истины для package identity.

Из контейнера извлекаются только:

- `.apk`;
- `.obb`.

Остальные файлы не участвуют в установке.

Для каждого APK программа отдельно выполняет `aapt2 dump badging` и проверяет:

- одинаковый package name;
- совместимый versionCode;
- ровно один базовый APK без `split`;
- отсутствие повторяющихся split names.

Неоднозначный набор не устанавливается.

## Split APK

Если XAPK содержит более одного APK, установка выполняется одной транзакцией:

`adb install-multiple -r -t -g <base.apk> <split...>`

Базовый APK всегда передаётся первым. Split-части сортируются воспроизводимо.

Программа не выбирает «похожий» base APK по имени файла и не пытается смешивать APK разных приложений.

## OBB

После успешной установки APK-набора каждый OBB-файл помещается в:

`/sdcard/Android/obb/<package name>/<obb filename>`

Каталог определяется только из package name, подтверждённого `aapt2`.

Если перенос OBB завершается ошибкой, подготовка приложения считается неуспешной и исследование не запускается автоматически.

## Безопасность контейнера

При распаковке XAPK:

- запрещены абсолютные пути;
- запрещены `..` и выход за временный каталог;
- зашифрованные члены ZIP не принимаются;
- ограничено количество APK/OBB;
- ограничен суммарный объём извлекаемых APK/OBB;
- повреждённый ZIP отклоняется.

Временная распаковка удаляется после завершения установки или ошибки.

## Границы

v0.27 не меняет:

- hidden Emulator → gRPC/MMAP → AndroidView;
- v0.10.5 startup/clean-launch sequencing;
- collectors;
- RAW PCAP;
- Research ZIP schemas;
- атрибуцию сети;
- временные и причинные границы evidence model;
- dual-source screen model.

Поддержка XAPK является только новым входным/установочным слоем до начала исследовательской сессии.

## Проверка

Обязательные проверки включают:

- разбор base/split badging;
- отклонение смешанных package names;
- требование ровно одного base APK;
- защиту от path traversal;
- реальную сборку команды `adb install-multiple`;
- перенос OBB;
- регрессию одиночного `adb install`;
- полный CI;
- реальную AVD Research ZIP acceptance;
- Windows standalone/GUI/installer acceptance.
