# v0.29 — Icon, ABI-aware XAPK and Emulator App Controls

## Цель

Исправить выявленные владельцем проблемы пользовательского пути после v0.28: техническую иконку, неочевидную установку приложения в эмулятор и XAPK-ошибку `INSTALL_FAILED_NO_MATCHING_ABIS`. Одновременно закрепить обновление существующей установки без предварительной деинсталляции.

## XAPK и ABI

После запуска управляемого Android программа читает `ro.product.cpu.abilist` (с резервом на `ro.product.cpu.abi`).

Для каждой APK-части XAPK `aapt2 dump badging` дополнительно извлекает `native-code`.

Перед установкой:
- базовый APK остаётся обязательным;
- package name/versionCode правила v0.27 сохраняются;
- split без native-code сохраняются;
- native split включается только при пересечении с ABI эмулятора;
- несовместимые ABI-split не передаются в `adb install-multiple`;
- если весь native-набор пакета несовместим, установка прекращается до adb install и показывается понятное сообщение;
- если Android всё же возвращает `INSTALL_FAILED_NO_MATCHING_ABIS`, сообщение переводится в явную диагностику package ABI ↔ emulator ABI.

## Установка в эмулятор

Выбор файла больше не запускает установку автоматически. В интерфейсе есть отдельные действия:
- «Установить в эмулятор»;
- «Запустить приложение»;
- «Открыть главный экран Android».

Исследование остаётся недоступным до успешной установки пакета.

## Иконка

Во время Windows-сборки проект генерирует единый набор PNG/ICO из собственного дизайна: смартфон, Android и лупа. Он применяется к Qt application icon, PyInstaller EXE, Inno Setup и ярлыкам.

## Обновление установленной программы

Автообновлятор передаёт `/UPDATE=1`. Inno Setup использует тот же AppId и:
- `UsePreviousAppDir=yes`;
- `UsePreviousGroup=yes`;
- `UsePreviousTasks=yes`;
- не вызывает старый uninstaller;
- обновляет программные файлы поверх существующей установки.

QSettings и данные исследований находятся вне набора программных файлов и не удаляются.

- полный CI;
