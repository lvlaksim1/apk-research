# apk-research v0.37.0 — текст и исходный HEX в HTTPS

**Текст (авто)** теперь выбран по умолчанию для просмотра тел HTTPS-запросов и ответов. Программа разбирает multipart/form-data на поля, форматирует JSON и распаковывает gzip/zlib, когда это подтверждено фактическим содержимым тела. В частности, поддерживаются наблюдаемые составные POST-запросы и ответы типа application/zlib. Уже распакованные HTTPS-анализатором данные не распаковываются повторно.

Режим **HEX** показывает сохранённые байты без преобразований. Он нужен для проверки бинарных форматов или случая, когда автоматическая обработка не распознала содержимое. При недостоверной текстовой интерпретации программа сохраняет HEX и сообщает причину.

Новые режимы действуют как в текущем HTTPS-анализе, так и при открытии сохранённых ZIP, включая окно просмотра транзакций. Распаковка и парсинг ограничены по объёму. Исходные пакеты, HTTP-тела, видеозапись, полная запись ZIP, метод/доменные фильтры, независимый HTTPS-анализ и работа Android остаются без изменений.

Ограничение: расшифровать неизвестный бинарный протокол по одному заголовку невозможно. После gzip/zlib внутри может остаться формат, для которого понадобится отдельный анализ. Программа не будет выдумывать его структуру.
