# apk-research v0.34.0 — Панель эмулятора и новые данные ZIP

Добавлена правая панель Android с кнопками «Назад», «Домой», «Последние», громкости, поворота, снимка экрана, полноэкранного режима, установки APK/XAPK и перезагрузки. Дополнительное меню: передать или получить файл, остановить/очистить приложение, открыть его настройки, задать координаты, имитировать встряску, ввести текст из буфера ПК.

Архив исследования пополнился файлами `dns.jsonl`, `tls-sessions.jsonl`, `network-timings.jsonl`, `action-network-links.jsonl`, `screen-timing.jsonl` и `network-enrichment.json`. Их содержимое выводится из исходных пакетов, HTTPS-журнала, действий и видео; исходные файлы не изменяются.

Из-за шифрования, QUIC/DoH, фрагментации и ограниченной длины обработки часть DNS/TLS-сведений может отсутствовать. Привязка действия к запросу обозначается как предположение по времени. Значения видеозаписи не позволяют автоматически доказать задержку реакции интерфейса.

Две основные вкладки «Исследование» и «HTTPS • онлайн» сохранены, а для обновления предусмотрен отдельный установщик. В ZIP могут содержаться конфиденциальные сведения, включая данные авторизации.
