# apk-research v0.37.1 — большие ответы gzip/zlib

Исправлено сообщение об ошибке распаковки для корректного большого zlib-ответа. Прежний предел 128 КиБ теперь ограничивает только текст одного отображаемого фрагмента, а не весь процесс распаковки.

Вкладки «Тело запроса» и «Тело ответа» поддерживают номер фрагмента рядом с выбором «Текст (авто) / HEX». Можно последовательно прочитать до 8 МиБ распакованного содержимого, не выводя его целиком в окно. Если данные превышают защитный предел, пользователь увидит частичный результат с предупреждением, а не ошибку размера. HEX по-прежнему показывает исходные сохранённые байты.

Изменение работает в режиме анализа HTTPS и при просмотре сохранённого ZIP. Исходные архивы и полные данные не изменяются. Неизвестные двоичные форматы после распаковки не преобразуются в выдуманный текст.
