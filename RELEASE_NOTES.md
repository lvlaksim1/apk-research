# apk-research v0.38.0 — форматирование JSON и повторная отправка запроса

В таблице HTTPS выделите запрос и нажмите **«Изменить и отправить…»**. Откроется отдельное окно, где можно изменить метод, адрес в пределах исходного сервера, заголовки и тело запроса. JSON автоматически показывается с отступами. Для непрозрачных бинарных данных доступен режим HEX.

Повторная отправка выполняется только после вашего подтверждения. Исходные сохранённые байты остаются неизменными, пока вы не внесли в тело правку. Результат отправки выводится в отдельные вкладки с кодом, заголовками и телом нового ответа. JSON ответа также красиво форматируется; можно переключиться на HEX. Ни исходный ZIP, ни работающий анализ HTTPS не переписываются.

**Важно:** запрос выполняет компьютер напрямую, а не Android-приложение. При повторе запроса могут не подойти авторизация, cookies, подпись, IP-адрес или сертификат. Отправка ограничена исходным HTTPS-сервером либо сохранённым Host без смены порта. Сертификат проверяется, автоматические перенаправления/повторы отключены; произвольный новый домен запрещён. Отправленный POST/PUT/PATCH/DELETE может изменить данные на сервере.

Предел передаваемого и возвращаемого тела — 8 МиБ. Служебные HTTP-заголовки пересчитываются для нового запроса; заголовок старого сжатия не переносится, потому что программа сохраняет тело после возможной распаковки.
