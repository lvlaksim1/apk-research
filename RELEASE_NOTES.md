# apk-research v0.32.0 — Анализ прямых HTTPS-соединений

## Новая возможность

Программа направляет HTTPS-соединения выбранного Android-приложения в локальный анализатор, в том числе когда приложение явно отключает системный прокси. Это выполняется только для IPv4 TCP/443 и только для UID выбранного приложения.

Для этой задачи добавлен компактный служебный модуль Android, который получает исходный адрес назначения сетевого соединения и использует уже существующий локальный HTTPS-анализатор. При штатном завершении исследовательского сеанса применённое сетевое правило удаляется.

В результатах сохраняются:
- читаемые HTTPS-запросы и ответы, если установлено необходимое доверие TLS;
- независимый журнал `01_raw/network/https-direct-route.log` с адресами соединений;
- метаданные направления соединений и неизменённый самостоятельный RAW PCAP.

## Проверка

В реальном Android 15 подтверждены два обращения к `https://example.com/`: через системный прокси и напрямую с `Proxy.NO_PROXY`. В обоих случаях получен ответ HTTP 200 с телом 577 байт. Завершающие проверки включают полное исследование Android, модульные тесты, сборку Windows и обновление предыдущей версии.

## Ограничения

Сохраняются ограничения на собственные хранилища доверия приложений, дополнительные проверки TLS и UDP/443 (QUIC). Реальные APK могут требовать индивидуальной диагностики. Другие приложения и их сетевые соединения не изменяются.

Предыдущая поддержка ARM64/XAPK в отдельном образе Google APIs сохранена.
