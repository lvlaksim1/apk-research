# apk-research v0.31.0 — поддержка ARM64 APK/XAPK

Программа автоматически определяет архитектуру APK/XAPK. Для приложений с ARM64-библиотеками она загружает официальный совместимый образ Android 15 (Google APIs / x86_64) и устанавливает пакет в отдельный управляемый эмулятор. Дополнительный образ загружается один раз при первом использовании.

Прежний эмулятор, его приложения и пользовательские данные сохраняются. Выбранный профиль запоминается после успешного запуска. Проверки целостности XAPK, соответствия ABI, работа экрана и формирование исследовательского архива остаются обязательными.

Проверка: модульные тесты, запуск ARM64 JNI-библиотеки в реальном Android 15, основной цикл Android-исследования и Windows-сборка.

Ограничение: поддержка ARM не гарантирует запуск любого приложения, если оно требует иных компонентов Android или проверяет подлинность устройства. Возможности системного преобразования инструкций определяются официальным образом Google APIs.
