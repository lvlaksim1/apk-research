# Project Identity

- Project: apk-research
- Repository: `lvlaksim1/apk-research`
- Visibility: public
- Product authority branch: `main`
- Manager-state authority branch: `context`
- Product type: standalone Windows desktop GUI for controlled Android application research.
- Primary user workflow: choose an APK/XAPK, start a managed research session, interact with the embedded Android view, finish the session, and inspect/export a `.research.zip` evidence bundle.
- Current release baseline: `v0.33.0` at `3f3f1144e0ea8944a065e7d5950fd07fd1e17abf`.

The project is evidence-oriented: raw capture remains authoritative while Timeline, Unified Session Evidence, network attribution, protocol intelligence, HTTP/HTTPS transaction analysis and Investigator Workspace provide derived navigation and analysis.
